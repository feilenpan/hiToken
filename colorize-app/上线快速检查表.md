## 📞 遇到问题？

### 技术问题
- 服务器部署问题 → 查看 `/var/log/colorize-app.log`
- 微信接口报错 → 查看微信公众平台后台日志
- Palette API 失败 → 检查 API Key 配置和余额

### 审核问题
- 被拒审 → 查看拒审原因，针对性修改
- 无法提交 → 检查是否所有必填项都已完成
- 域名报错 → 确认域名已备案且添加到白名单
