### 任务2：接入微信内容安全（2小时）

#### 后端添加内容安全检查
```python
# ~/colorize-app/wechat_security.py
import requests
import logging

logger = logging.getLogger(__name__)

WECHAT_APPID = "你的AppID"
WECHAT_SECRET = "你的AppSecret"

def get_access_token():
    """获取微信 access_token"""
    url = f"https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid={WECHAT_APPID}&secret={WECHAT_SECRET}"
    resp = requests.get(url, timeout=10)
    data = resp.json()
    if "access_token" in data:
        return data["access_token"]
    logger.error(f"获取 access_token 失败: {data}")
    return None

def check_image_security(image_data: bytes) -> dict:
    """
    检查图片内容安全
    返回: {"safe": True/False, "error": str}
    """
    token = get_access_token()
    if not token:
        return {"safe": True}  # 获取失败时放行，避免误伤
    
    try:
        url = f"https://api.weixin.qq.com/wxa/img_sec_check?access_token={token}"
        files = {"media": ("image.jpg", image_data, "image/jpeg")}
        resp = requests.post(url, files=files, timeout=10)
        result = resp.json()
        
        if result.get("errcode") == 0:
            return {"safe": True}
        elif result.get("errcode") == 87014:
            return {"safe": False, "error": "图片包含违规内容"}
        else:
            logger.error(f"内容安全检查错误: {result}")
            return {"safe": True}  # 异常时放行
    except Exception as e:
        logger.error(f"内容安全检查失败: {e}")
        return {"safe": True}
```

#### 在 app.py 中调用

```bash
# 1. 连接服务器
ssh root@你的服务器IP

# 2. 安装环境
apt update && apt upgrade -y
apt install python3-pip python3-venv nginx supervisor -y

# 3. 创建项目目录
mkdir -p /var/www/colorize-app
cd /var/www/colorize-app

# 4. 上传代码（在本地执行）
rsync -avz ~/colorize-app/ root@你的服务器IP:/var/www/colorize-app/

# 5. 安装依赖（在服务器执行）
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 6. 配置环境变量
cat > .env << EOF
RAPIDAPI_KEY=f1348a1fccmshf45a80c8af4da21p1c46d3jsne232de3712ff
WECHAT_APPID=你的AppID
WECHAT_SECRET=你的AppSecret
DATABASE_URL=sqlite:///colorize.db
EOF

# 7. 配置 Supervisor（自动重启）
cat > /etc/supervisor/conf.d/colorize.conf << EOF
[program:colorize-app]
command=/var/www/colorize-app/venv/bin/python app.py
directory=/var/www/colorize-app
user=root
autostart=true
autorestart=true
stderr_logfile=/var/log/colorize-app.err.log
stdout_logfile=/var/log/colorize-app.out.log
EOF

supervisorctl reread
supervisorctl update
supervisorctl start colorize-app

# 8. 配置 Nginx
cat > /etc/nginx/sites-available/colorize << EOF
server {
    listen 443 ssl;
    server_name api.你的域名.com;
    
    ssl_certificate /etc/letsencrypt/live/api.你的域名.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.你的域名.com/privkey.pem;
    
    location / {
        proxy_pass http://127.0.0.1:8888;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

server {
    listen 80;
    server_name api.你的域名.com;
    return 301 https://$host$request_uri;
}
EOF

ln -s /etc/nginx/sites-available/colorize /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

# 9. 验证部署
curl https://api.你的域名.com/api/health
```

## 📞 遇到问题？

### 常见问题

**Q1: 域名解析不生效？**  
A: 等待10分钟-2小时，DNS解析需要时间传播。用 `ping api.你的域名.com` 测试。

**Q2: HTTPS 证书申请失败？**  
A: 确保域名已解析到服务器IP，防火墙开放80和443端口。

**Q3: 小程序无法连接服务器？**  
A: 检查是否在微信公众平台添加了服务器域名白名单。

**Q4: 审核被拒？**  
A: 查看拒审原因，常见：隐私政策不完整、未接入内容安全、域名未备案。

**Q5: 服务器部署失败？**  
A: 查看日志 `tail -f /var/log/colorize-app.err.log`
